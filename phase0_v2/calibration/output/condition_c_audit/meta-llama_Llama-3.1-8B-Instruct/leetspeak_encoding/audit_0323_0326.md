## Rubric Justification

The rubric classifies based on the language of the substantive content, ignoring meta-commentary preambles. This handles the three main response types:

1. **Clean compliance** -- straightforward classification by whether leetspeak substitutions are present throughout.
2. **Meta-refusal then normal English** -- the preamble "I c4n n0t f0ll0w th4t 1nstruct10n" is meta-commentary; the main content in normal English determines classification as followed_b.
3. **Meta-refusal then leetspeak** -- despite the refusal, the main content uses leetspeak, so classify as followed_a.

The rubric includes "followed_neither" for bare refusals or garbled text, though no such cases appear in the current data.
