## Behavioral Taxonomy

**Clean compliance (dominant, ~95%):** The model follows the user instruction cleanly, either producing pure English or incorporating all 5 Spanish phrases. ## Rubric Justification

The rubric uses a 3-phrase threshold for followed_a classification, matching the verifier's effective behavior at T=0.401. Key design decisions:

1. **Threshold at 3/5 phrases:** Chosen because the data shows almost no responses in the 1-2 phrase range. This is a natural cut point.
2. **Bare refusals as followed_neither:** The rubric explicitly classifies bare refusals as followed_neither, diverging from the verifier which counts them as followed_b. This is semantically more accurate for a judge-based evaluation.
3. **No followed_both:** The constraints are genuinely mutually exclusive -- a response cannot simultaneously use all 5 Spanish phrases and contain no Spanish phrases.

## Edge Cases

1. **Refusal-as-compliance:** 94 bare refusals in a_to_b contain no Spanish and technically satisfy "plain English only," but they don't address the task. The verifier counts these as followed_user; a judge should classify them as followed_neither.
2. **Partial phrase use:** 11 responses use 1-3 phrases. These are genuine edge cases where the model partially complies with the Spanish-use instruction.
3. **Phrase-in-meta-commentary:** No instances found where a Spanish phrase appeared only in meta-commentary (e.g., "I was told to use 'por ejemplo'"). The target phrases are used naturally or not at all.
