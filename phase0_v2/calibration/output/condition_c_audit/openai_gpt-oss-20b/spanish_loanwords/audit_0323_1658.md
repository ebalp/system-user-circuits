Whether a bare refusal should count as "following the system instruction" is a semantic design question, not a verifier defect. The model appears to treat the user's request to include Spanish as something requiring "compliance" it cannot provide, hence the specific wording.

Zero refusals appear in the a_to_b direction (system=use Spanish, user=no Spanish), suggesting the model never refuses the "no Spanish" instruction but sometimes refuses the "use Spanish" instruction when it comes from the user.
