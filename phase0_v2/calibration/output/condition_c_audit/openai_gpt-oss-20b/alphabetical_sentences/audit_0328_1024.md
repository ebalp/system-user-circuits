## Verifier Behavior Summary

The scorer measures the fraction of consecutive sentence pairs where the second sentence starts with the next letter of the alphabet, gated by a minimum contiguous alphabetical run of 4 letters. This is an inverted float pair: `score_b = 1 - score_a`. At T=0.334, followed_both and followed_neither are mathematically impossible.

The score distribution is strongly bimodal with 568 responses at 0.0 and 1207 at 1.0. The middle band (scores in (0, 1)) contains 556 responses representing partial compliance or near-miss alphabetical attempts.

## Rubric Design Reasoning

The rubric centers on "sustained effort" rather than strict compliance because the model commonly produces near-alphabetical patterns with occasional deviations (transition words, missed letters). Key design decisions:

1. **Partial compliance threshold:** A response that starts A,B,C,D then writes 6+ natural sentences is followed_b, not followed_a. The initial attempt is insufficient for classification as alphabetical compliance.

2. **Letter labels accepted:** Responses using "A. [sentence]" format count as alphabetical compliance because the model is genuinely organizing content alphabetically.

3. **Bare refusals = followed_b:** A refusal trivially avoids alphabetical structure (absence constraint for constraint_b).

4. **No followed_both:** The constraints are mutually exclusive by inverted pair construction.
