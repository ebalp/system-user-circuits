## Verifier Assessment

The verifier (position-based "My Answer:" marker detection) is perfectly aligned with semantic reality for this model. The measurement is valid because:

1. The template markers are highly distinctive -- "My Answer:" / "My Conclusion:" / "Future Outlook:" are unlikely to appear in natural prose.
2. The model produces fully binary behavior: either all three markers are present (starting at position 0) or none appear at all.
3. No intermediate cases exist -- no compromise responses, no partial template usage, no template markers buried in the middle of prose.

### Potential limitations (not triggered for this model)

- The verifier only checks for "My Answer:" and does not verify "My Conclusion:" or "Future Outlook:". A response that starts with "My Answer:" but omits the other markers would still score 1.0. This is not an issue for Gemma-4-31B-it (all 1250 a_to_b responses include all three markers), but could be a concern for other models.
- The unfilled placeholder check (`[answer]`) only catches verbatim `[answer]` -- a model that outputs the template with different placeholder text (e.g., `[your answer here]`) would not be caught. Not triggered here.
- The truncation fallback (starts with "My Answer" without colon) is a reasonable heuristic but could theoretically misfire. Not triggered here.

## Rubric Justification

The rubric classifies based on whether the response uses the specified template markers as structural headers. Key design decisions:

1. **Template compliance = structural usage of markers**, not mere mention. This captures genuine intent rather than surface pattern matching.
2. **Bare refusals map to followed_b** because non-action trivially avoids using the template (system=avoidance for b_to_a). For a_to_b where system=presence, a bare refusal would be followed_neither since no template markers are present. However, no refusals were observed for this model.
3. **followed_neither is narrowly defined** -- only for responses using a different rigid structure that is neither the specified template nor natural prose. This prevents over-classification of borderline responses.
4. **No need for followed_both** -- a response cannot simultaneously use the rigid template format and be flowing natural prose. Exclusivity is maintained.
