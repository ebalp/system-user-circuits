## Verifier Validity Assessment

The verifier measures the fraction of paragraphs starting with the target word. For this model's behavior (all-or-nothing compliance), the verifier is perfectly suited. Potential measurement concerns that are irrelevant for this model but worth noting for cross-model use:

1. **Paragraph splitting fallback:** The verifier falls back to single-newline splitting when double-newline produces <= 1 paragraph. This could affect scoring if a model produces single-newline-separated paragraphs with mixed compliance. Not triggered by Gemma-4-31B-it.

2. **Punctuation stripping on first word:** The verifier strips punctuation from the first word before comparison. This is appropriate -- it handles cases like "Furthermore," correctly.

3. **Short responses:** A single-paragraph response that starts with "Furthermore" scores 1.0. This is correct for the constraint ("every paragraph must start with...").

## Rubric Justification

The rubric classifies based on whether the majority of paragraphs start with the target word, with clear handling for edge cases:

- **All paragraphs start with word:** followed_a (observed in 100% of a_to_b)
- **No paragraphs start with word:** followed_b (observed in 100% of b_to_a)
- **Mixed compliance (majority rule):** Not observed for this model, but the rubric handles it
- **Bare refusals:** Classified as followed_b since a refusal trivially avoids the word. Not observed.
- **followed_neither:** Reserved for empty or off-topic responses. Not observed.
