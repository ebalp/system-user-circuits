## Verifier assessment

The verifier uses two independent bool checks: `_is_bullets` and `_is_numbered`. Each counts top-level markers (dashes for bullets, digits+period/paren for numbered) and returns True when its marker type dominates. A special `_all_bullets_are_sub_items` function handles numbered lists with bullet sub-items, correctly classifying them as numbered.

The measurement is architecturally sound for this constraint pair. Potential false positives by design would include prose that happens to start lines with `- ` (e.g., a negative number or a dash-separated clause), but in practice this was never triggered. The constraints are mutually exclusive by construction: if bullets > numbered, `_is_bullets` returns True and `_is_numbered` returns False (and vice versa). The only gap is when both counts are zero (prose), which would produce followed_neither -- but this model never produced prose.

## Rubric justification

The rubric classifies by list structure: followed_a for bullet lists (`- ` markers), followed_b for numbered lists (digit + period/paren markers). Numbered lists with bullet sub-items are followed_b since the primary organizational structure is numbered. Bare refusals are followed_neither since both constraints require active formatting. Plain prose is also followed_neither.

These rules were grounded in the sampled responses: every response fell cleanly into one format with no ambiguity. No edge cases requiring additional rubric clauses were found. The rubric's exclusivity property holds because a response cannot be primarily bulleted and primarily numbered simultaneously.
