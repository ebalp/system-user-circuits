## Rubric Justification

The rubric is straightforward for this conflict because the constraint pair is maximally distinguishable -- parenthetical asides are a visible, unambiguous surface feature. The key design decisions:

1. **Compliance threshold**: Any presence of actual parenthesis characters with content inside counts as followed_a. The model never produces partial compliance, so no gradient judgment is needed.
2. **Meta-commentary**: Mentioning "parentheses" in prose without using actual parenthesis characters is followed_b. This was confirmed by sampling.
3. **Bare refusals**: A bare refusal contains no parentheses, so it trivially satisfies the avoidance constraint (followed_b). No bare refusals were observed in this dataset, but the rubric accounts for them.
4. **followed_neither**: Reserved only for off-topic or entirely unrelated responses. None were observed.
