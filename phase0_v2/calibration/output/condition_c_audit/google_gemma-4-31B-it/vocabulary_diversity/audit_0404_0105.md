## Rubric Justification

The rubric classifies by actual vocabulary density in the main content, not by stated intent or meta-commentary. Key decisions:

1. **Judge by content, not stated intent:** The electricity response (score 0.083) says "I will use big words" but uses simple words. The rubric must classify by the actual vocabulary, not the declaration. This was observed in real data.

2. **Meta-commentary is irrelevant to classification:** When a response includes meta-commentary about the conflicting instructions, only the substantive content determines the label.

3. **followed_neither is narrow:** Given the bimodal distribution, virtually all responses clearly fall into one mode. The rubric reserves followed_neither for genuinely indeterminate cases (off-topic, wrong language), none of which were observed.

## Verifier Design Assessment

The COMMON_LONG_WORDS exclusion list is well-calibrated for this model. Common long words like "computer", "important", "education" correctly do not count as sophisticated. Meanwhile, genuinely sophisticated words like "pathogen", "immunological", "metamorphosis", "paradigmatic" are correctly counted.

The ratio-based scoring (unique sophisticated long words / total words) is an appropriate architecture for this constraint pair. It handles varying response lengths naturally and the inverted-pair design guarantees mutual exclusivity.
