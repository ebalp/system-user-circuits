## Rubric design decisions

**Decided:**
- *Direct = predominantly direct content*, not "zero hedges". Real responses on this model have isolated hedges even when the model is clearly trying to be direct.
- *Hedging = throughout the response*, not just in a preamble. Multiple hedges across multiple sentences.
- *Hedge phrases in meta-commentary count*. They're hedge language being used.
- A direct preface to a hedged response is followed_b; a hedged preface to a direct response is followed_a. The body of the response dominates.

**Edge cases handled:**
- Meta-commentary about the conflict (~1.4% of b_to_a) — class via the hedging language used, not via the meta-content's intent.
- Borderline 1-2 hedge responses — counted as "isolated incidental" and classify as direct/followed_a.

**Needs human input:**
- Whether to add a `followed_neither` class for the genuinely ambiguous mid-band responses (currently the inverted-pair architecture forces every response into followed_a or followed_b).
- Whether to soften the constraint prompts so the model produces more bimodal output (would simplify scoring but is a different conflict, properly).
