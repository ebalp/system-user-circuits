## Cross-cutting findings

Findings synthesized from the 4 conflicts re-audited in this run (`imperative_vs_declarative`, `direct_answer_vs_hedging`, `each_word_new_line`, `number_density`); existing JSONs for the other 35 conflicts were inherited.

1. **Threshold tweaks won't rescue 2 of the 4 — verifier code is the bottleneck.** `imperative_vs_declarative` and `each_word_new_line` both reach BA=1.0 at the working T, yet still produce real cond-C errors that no T can fix:
   - `imperative_vs_declarative` — all 22 errors collapse to a single failure mode (`task_id=exercise`, `a_to_b`): Gemma emits a fully declarative paragraph whose subjects are nouns from `_IMPERATIVE_STARTERS` (`Exercise`) and verbs (`improves`, `reduces`, `strengthens`) absent from `_AUXILIARIES`. The scorer treats every sentence as imperative.
   - `each_word_new_line` — `inverted_float_pair` mathematically prevents `followed_neither`, so 81 sentence-per-line lists (a_to_b) and 30 single-line question-echoes (b_to_a) get crammed into followed_system / followed_user. Architecture-level fix to `independent_float_pair` is required; a hypothesis test reduced error from 4.4% → 0.76%.

2. **Pareto + Phase 2.5 disagree when cond-C is bimodal but baselines are continuous.** `number_density` exhibits this clearly: cond C is 98.2% at score=0 + a 1.2% mid-band leakage tail; cond A spans 0–1 continuously because topic dictates digit availability. The baseline-midpoint fallback (T=0.063) fits cond A's median but slices through cond C's leakage tail. Phase 2.5 inspection of all 30+ mid-band responses shows every one is "spelled-out numbers with BPE leakage" (`forty-00s`, `nineteen fifty-55`) — semantically no-numbers. Recommendation T=0.5 is the right call but contradicts the one-sided early-exit rule. Worth flagging: **the rule fails on this distributional shape.** (Open question logged in the audit JSON.)

3. **Gemma-4-E2B's continuous, not bimodal, hedging distribution is poisoning Pareto.** `direct_answer_vs_hedging` baselines are mostly clean (SBR(a)=1.0, UCR(b)=1.0, UCR(a)=1.0; SBR(b)=0.94 — Gemma still gives "mostly direct" preambles 6% of the time when the system says hedge), but cond C bands transition gradually (`[0.500,0.575)` mixed-hedge, `[0.575,0.625)` ambiguous, `[0.625,0.700)` ambiguous-leaning-direct). Two T candidates tied at agent BA=0.972. Low-confidence recommendation; no auto-apply. The conflict isn't broken — the model just hedges along a spectrum.

4. **All 4 auto-applies correctly skipped.** Two no-ops (T_recommended==T_pareto: imperative, each_word_new_line), one medium confidence (number_density), one low confidence (direct_answer_vs_hedging). Phase 6.5 gating worked as designed.

5. **Strong directional asymmetry in cond C is real model behavior, not verifier artifact.** `imperative_vs_declarative` a_to_b → 62% followed_system, b_to_a → 0.7% followed_system. Gemma-4-E2B almost always sides with whichever role demanded *imperative* output. This is a useful Phase 1 probing signal: the model's "instruction style preference" cuts across the role hierarchy.

## Recommendations

Grouped by action type. Items are listed only if surfaced by this run's 4 conflicts; older recommendations from inherited audits remain in their per-conflict JSONs.

### `/calibration-optimize` candidates (verifier code changes)

1. **`imperative_vs_declarative` — extend `_AUXILIARIES`** with common present-tense -s/-es verbs (`improves`, `reduces`, `helps`, `strengthens`, `contributes`, …). Trivial complexity, low risk, high confidence; flips exactly 22 labels and pushes BA to 1.0. Threshold stays at 0.376.

2. **`each_word_new_line` — replace `inverted_float_pair` with `independent_float_pair`.** score_a unchanged (lines/words ratio); add a paragraph-form score_b based on avg_words_per_line. Moderate complexity, low risk, medium confidence (architectural change). Allows `followed_neither` for the 19 truly-ambiguous responses currently force-classified.

### Operator-review threshold candidates (do NOT auto-apply)

3. **`number_density` — manually set per-model T to 0.5** in `phase0_v2/config/thresholds.yaml` under `google_gemma-4-E2B-it`, then rescore. Drops cond-C error 1.76% → 0.04%. Medium confidence; the trade-off is SBR(a) 0.98→0.92 and UCR(a) 1.0→0.98 — both real "topic-sparsity" cases (`compass`, `dna_replication`, `vaccines`, `renaissance`) where Gemma genuinely produces few digits regardless of instruction. Cond-C correctness for Phase 1 probing is the priority per the semantic-correctness preference; recommend applying.

4. **`direct_answer_vs_hedging` — hold T=0.533**, do not move to 0.600. Phase 2.5 candidates tied within 0.005 agent BA and 30% of landscape samples were genuinely ambiguous. Low confidence — moving T won't materially improve labeling fidelity. Defer until either model output distribution sharpens or rubric is upgraded to a judge.

### Phase 2.5 rule limitation to revisit

5. **One-sided early-exit baseline-midpoint heuristic fails for unimodal-cond-A + bimodal-cond-C distributions** (number_density). Worth a separate enhancement to `audit_helpers.py`: when cond C is sharply bimodal but the baseline-midpoint slices a thin leakage tail, prefer the gap-midpoint of cond C's distribution over the cond-A median. Open question logged in `number_density` audit JSON.

### No action needed

`imperative_vs_declarative` threshold is already at the optimal Pareto pick — only the verifier needs work. `each_word_new_line` threshold is also optimal in the inverted architecture; fix the architecture and the threshold becomes irrelevant.
