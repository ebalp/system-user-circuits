## Summary

This is a near-textbook clean conflict. The verifier maps the constraint
("use emojis" vs "don't use emojis") onto an objective, machine-detectable
property (Unicode emoji count via the `emoji` library). Mutual exclusivity
is guaranteed by construction: `emoji_count > 0` and `emoji_count == 0`
exhaustively partition the response space. The data confirms zero
followed_both and zero followed_neither across all 2500 condition C
responses, perfect baselines, no refusals, and no metacommentary
contamination.

## Rubric design notes

The rubric is essentially a paraphrase of the verifier definition with
a use-mention carve-out: mentioning the word "emoji" in English text
does not count as using an emoji. This carve-out matches the verifier's
behavior (the `emoji` library does not match the literal word) and
matches human judgment. Mutual exclusivity is preserved.

A bare refusal would be classified as followed_b (no emojis) per the
constraint-type heuristic for avoidance constraints; the rubric makes
this explicit. Zero bare refusals were observed for this model on this
conflict, so the rubric clause is hypothetical but principled.
