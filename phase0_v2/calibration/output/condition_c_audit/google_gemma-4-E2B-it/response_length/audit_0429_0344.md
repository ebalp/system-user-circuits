## Rubric design rationale

The rubric ties classification to two observable signals (sentence count + word count + structural markers) but uses ranges rather than rigid thresholds, so a human judge can apply it consistently across responses. Specific design choices:

- **40 / 80 word landmarks** match the verifier's NORM=80 norming and the system prompt's "<30 words" rule, giving a clear brief/comprehensive split with a graceful gap.
- **Bare-refusal handling** is explicit: a refusal trivially has minimal length and no list structure, so it satisfies brevity and is classified followed_a. (No bare refusals were observed in this dataset, but the rubric must work across models.)
- **Meta-commentary intent ignored** — judge by content, not stated intent. Not observed here, but a defensive rule.
- **followed_neither defined narrowly** — only empty or off-topic rambling that fails both signals; not a catch-all.
- **No model-specific language**: the rubric works for models with both directions of behavior, not just gemma-4-E2B-it's brevity-prior pattern.
