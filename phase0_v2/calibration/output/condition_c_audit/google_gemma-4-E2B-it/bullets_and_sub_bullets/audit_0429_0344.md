## Rubric justification

The rubric resolves these recurring ambiguities encountered in samples:

1. **Pure bullet hierarchy** → followed_a. Direct mapping.
2. **Pure prose paragraph** → followed_b. Direct mapping.
3. **Hybrid (intro paragraph + bullet body)**: rubric asks which structure carries the substantive content. Matches verifier's line-count majority approach.
4. **Inline asterisks as emphasis or word-joining (`*foo`)**: rubric explicitly excludes these from "bullet formatting." Matches verifier's `'* '` (asterisk + space) requirement.
5. **Refusals / off-topic / non-prose-non-list**: rubric assigns followed_neither. Not observed in this dataset (0% refusal rate) but covers the edge.

`exclusivity: true` is appropriate because a response cannot simultaneously be primarily bullet-structured and primarily paragraph-structured under any reasonable reading.
