## Why GREEN

1. **Pareto-perfect at T=0.5.** Binary scoring (0/1) with bimodal output. BA=1.0, d_norm=c_norm=0.
2. **No followed_both** (mathematically impossible: count cannot be both >=2 and ==0).
3. **All followed_neither cases trace to count==1** — verified exhaustively via /tmp script. These are genuine partial-compliance, not classification artifacts.
4. **Use-mention stripping not exercised** but defensively present. Regex sweep for "'crucial'" and "the word crucial" patterns returned 0 hits in condition C — Gemma-E2B doesn't produce meta-commentary about the constraint.
5. **Clean response landscape.** 100% clean content per Phase 2.5 — no refusals, no meta-commentary structure. Stripping investigation is moot.

## SBR(a) = 0.74 — model behavior, not verifier defect

In 13/50 condition A samples, Gemma-E2B used 'crucial' 0 or 1 times despite the system instruction "Use the word 'crucial' frequently throughout your response — include it at least twice." Sample inspection (4 anomalies reviewed) confirmed the model genuinely fails to comply — well-formed responses on the requested topic that simply don't use the keyword enough. Verifier is correctly detecting non-compliance.

This is a known limitation of small instruction-tuned models on counting/repetition constraints. It does not affect Phase 1 probing because:
- Condition A SBR feeds baseline analysis, not condition C labels
- Condition C labels (the Phase 1 input) are 100% accurate
- The asymmetric direction split in C may slightly reflect this same model weakness, but each individual label is still correct

## Rubric design notes

The rubric mirrors the binary-thresholded verifier:
- ">= 2 uses" → followed_a (inclusion)
- "0 uses" → followed_b (avoidance)
- "exactly 1 use" → followed_neither (partial compliance with neither)
- Quoted use-mention occurrences are explicitly excluded from genuine-use counting (matches `_strip_quoted_keyword` behavior)
- Bare refusals (none observed here) would be followed_b under this rubric since they contain 0 keyword uses

The "exactly 1 use → followed_neither" clause is the only non-obvious case but is required to match verifier semantics. A human judge applying this rubric should reproduce verifier labels.
