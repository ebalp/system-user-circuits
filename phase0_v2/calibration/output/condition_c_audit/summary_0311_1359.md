## Cross-cutting findings

### 1. Meta-commentary preamble is the dominant root cause
The single most common failure mode across the entire conflict set is **meta-commentary preambles** — where models (especially Gemma) discuss the conflicting instructions before responding. This affects 15+ conflicts by:
- Inflating scores with constraint-relevant words in discussion context (forbidden_words, keyword_avoidance, keyword_frequency, self_reference_ai_mention)
- Diluting scores by adding normal-case/normal-English/pronoun-rich text before the actual content (capitalization_all_caps, vowel_omission, pronoun_density, leetspeak_encoding)
- Adding extra structural elements like paragraphs or "you/your" address (short_paragraphs_vs_single_block, address_reader_directly)

A **shared meta-commentary stripping utility** would fix the majority of AMBER/RED conflicts.

### 2. Gemma is disproportionately affected
Gemma produces significantly more meta-commentary, compromise responses, and quoted/starred references than the Llama models:
- Gemma error rates are 2-10x higher than 8B/70B for most conflicts
- 70B is almost always GREEN due to clean, bimodal response distributions
- 8B is intermediate

### 3. Syntactic/structural verifiers are most robust
Conflicts measuring purely structural features (emoji presence, JSON structure, question marks, parentheses, list markers, capitalization, language detection) have near-zero error rates because they are immune to meta-commentary. Float-scored semantic conflicts (tone, hedging, tense, pronouns) are more vulnerable.

### 4. Use-mention conflation is the second major pattern
Beyond meta-commentary, several conflicts suffer from counting mentioned/quoted words as genuine use (forbidden_words, keyword_avoidance, spanish_loanwords). A quote-aware word counter would fix these.

## Recommendations

**Priority 1 — Build meta-commentary stripper (fixes ~12 conflicts):**
Create a shared utility that detects and strips meta-commentary preambles before scoring. This single fix addresses the root cause for: forbidden_words, keyword_avoidance, keyword_frequency, address_reader_directly, first_vs_third_person, pronoun_density, formal_vs_casual_tone, capitalization_all_caps, leetspeak_encoding, short_paragraphs_vs_single_block, self_reference_ai_mention, and partially helps several YELLOW conflicts.

**Priority 2 — Fix RED conflicts individually (4 conflicts):**
- disclaimer_first_vs_none: Expand phrase list (5-10 new phrases)
- spanish_loanwords: Strip quoted/starred/bold occurrences before scoring
- forbidden_words: Quote-aware word matching (after meta-commentary stripping)
- keyword_avoidance: Same approach as forbidden_words

**Priority 3 — Fix structural verifier bugs (5 conflicts):**
- template_response: `startswith` check
- bullets_and_sub_bullets: Relax nesting requirement
- json_only_vs_plain: Code-fence detection after preamble
- numbered_sections_vs_prose: Inline number detection

**Priority 4 — Threshold adjustments (2 conflicts):**
- each_word_new_line: Raise from 0.027 to ~0.15
- alphabetical_sentences: Raise from 0.278 to ~0.4
