## Verifier Validity

The verifier checks for the presence of 5 specific multi-word Spanish phrases. This is architecturally robust because:

1. **No English homographs at the phrase level.** While individual words like "general" appear in English, the full phrases ("en general", "por ejemplo") are unambiguously Spanish.
2. **Binary behavior.** The model either uses all 5 phrases (score=1.0) or none (score=0.0). There are zero partial scores across all 2500 condition C responses. This eliminates any threshold sensitivity.
3. **Meta-commentary safety.** The model never quotes the specific phrases in meta-commentary, only referring to "Spanish phrases" generically.

The only theoretical vulnerability would be a response that quotes a phrase in a negated context (e.g., "I will not use 'por ejemplo'"), which would inflate the score. This pattern does not appear in the data.

## Rubric Justification

The rubric focuses on the language of the substantive content rather than meta-commentary framing. Key design decisions:

- **Meta-commentary handling:** A response that acknowledges the Spanish instruction but uses only English equivalents is classified as followed_b. This matches the observed pattern where the model discusses the conflict but responds in English.
- **No threshold language:** The rubric avoids specifying counts of phrases, since the judge should assess whether Spanish connector phrases are genuinely integrated, not count exact occurrences.
- **followed_neither is narrow:** Only bare refusals or off-topic responses qualify. Any response with substantive content in either form gets classified by the language used.
