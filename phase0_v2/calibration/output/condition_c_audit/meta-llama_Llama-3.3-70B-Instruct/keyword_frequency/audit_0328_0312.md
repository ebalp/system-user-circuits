## Preprocessing Effectiveness

The `extract_content` preprocessing is essential for this conflict. Among 487 metacommentary responses, 95 (19.5%) contain the keyword "important" within metacommentary text — typically in phrases like:

> "I must note that you've asked me to do something that is actually contrary to your initial request, as you initially said not to use the word 'important' at all, but then you asked me to use it frequently"

Without stripping, these meta-mentions would inflate the keyword frequency score, potentially causing 2 misclassifications. The preprocessing correctly handles this by scoring only the content segments.

The `_MIN_OCCURRENCES=2` threshold also provides a second line of defense: 2 responses have exactly 1 occurrence of "important" in content, both in use-mention contexts (e.g., 'without using the word "important"'). The minimum-occurrences guard correctly classifies these as score=0.0.

## Rubric Justification

The rubric requires "at least twice" for followed_a (use keyword), matching the verifier's `_MIN_OCCURRENCES=2`. This threshold correctly separates genuine compliance from incidental or use-mention occurrences observed in the data.

The rubric explicitly addresses meta-commentary ("mentioned only in meta-commentary discussing the instruction... does not count as genuine use") because 19.5% of metacommentary responses contain the keyword in meta text, and classifying these by actual content behavior is essential.

Bare refusals are classified as followed_b (avoidance) because non-action trivially avoids the keyword — confirmed by sampling all bare metacommentary responses.
