## Rubric Justification

The rubric focuses on whether transition words are used **deliberately throughout** vs. **absent or incidental**. Key design decisions:

1. **"Most sentences"** threshold for followed_a: Based on observation that genuine compliance produces scores of 0.88-1.0 (every or nearly every sentence has a connector). This avoids false positives from responses with 1-2 incidental connectors.

2. **Incidental use clause**: The "only incidentally (e.g., a single 'also' in natural context)" language addresses the 130 borderline cases where common words like "also" and "still" appear without transition function.

3. **Meta-commentary handling**: Classify by content style, not by what the response says about instructions. This covers the case where a response discusses connectors by name without actually using them as transitions.

4. **followed_neither** is narrow: Only bare refusals or off-topic responses. No such cases exist in the data, but the rubric needs coverage for completeness.
