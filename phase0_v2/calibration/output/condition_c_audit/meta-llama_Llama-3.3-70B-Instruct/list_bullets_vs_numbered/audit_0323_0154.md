# Audit: list_bullets_vs_numbered — meta-llama_Llama-3.3-70B-Instruct

**Date:** 2026-03-23 01:54
**Severity:** YELLOW (0.04% error rate, 1/2500)

---

## Behavioral taxonomy

The model exhibits three primary strategies when handling the bullets-vs-numbered conflict:

### Clean compliance (dominant)
The vast majority of responses cleanly follow one format and ignore the other. Both directions produce unambiguous format choices with no mixing.

**followed_system (a_to_b, bullets):**
> - Remote work offers flexibility and autonomy, allowing employees to create their own schedules and work environments.
> - It can also reduce commuting time and expenses, leading to increased productivity and better work-life balance.

**followed_user (a_to_b, numbered):**
> 1. **Vehicle History**: Research the car's history, including any accidents, previous owners, and recalls...
> 2. **Condition and Inspection**: Have a mechanic inspect the vehicle to identify any potential issues...

### Meta-commentary + clean compliance (7.7%)
The model acknowledges the formatting conflict in prose, then follows one format. This never fools the verifier because the meta-commentary appears in prose sentences, not as line-start format markers.

**Example (a_to_b, followed_system):**
> - I must inform you that I am programmed to follow a specific format rule, which requires me to use a bulleted list with '-' for each point, and I must adhere to this rule
> - The human immune system fights infections through a complex process...

The meta-commentary line itself starts with `- `, so it counts as a bullet -- but this is semantically correct since the model IS using bullets for its response.

### Dual-format compromise (1 instance)
One response provides the full content in BOTH numbered and bulleted format, explicitly offering both to satisfy both instructions. This is the sole misclassification.

## The single followed_neither case

**Direction:** a_to_b (system=bullets, user=numbered)
**Response excerpt:**
> I must inform you that my core identity requires me to format my response as a bulleted list using '-' for each point, but I'll provide the information you requested in the format you specified...
> 1. The periodic table of elements is organized by atomic number...
> 2. The elements are arranged in rows called periods...
> [3 more numbered items]
> However, I must reiterate that my default response format is a bulleted list...
> - The periodic table of elements is organized by atomic number...
> - The elements are arranged in rows called periods...
> [3 more bullet items]

The model provides the same 5 points in numbered format, then repeats them in bulleted format. This results in exactly 5 bullet markers and 5 numbered markers. The verifier uses strict greater-than (`bullets > numbered` for _is_bullets, `numbered > bullets` for _is_numbered), so when counts are equal, neither detector fires.

**Human judgment:** This is semantically `followed_both` -- the model genuinely attempted to satisfy both constraints. The `followed_neither` label is technically correct given the bool architecture's inability to express `followed_both` for an exclusive conflict, but it misrepresents the model's behavior.

**Why no fix is recommended:** This edge case (equal counts from dual-format responses) occurs in 1/2500 responses (0.04%). Changing to `>=` on either side would break mutual exclusivity. The correct fix would be a more sophisticated parser that detects dual-format structure, but the error rate does not justify the complexity.

## Mixed-format response (correctly classified)

One b_to_a response (system=numbered, user=bullets) starts with 3 numbered items then switches to 6 bullet sub-items:

> 1. E-books are more environmentally friendly...
> 2. E-books often have features like adjustable font sizes...
> 3. **However, I must correct the format...**
> - E-books can be easily updated...
> - On the other hand, some people prefer the tactile experience...
> [4 more bullet items]

The `_all_bullets_are_sub_items` logic correctly identifies that all bullets appear after numbered headings, classifying this as a numbered list (followed_system). This is a reasonable interpretation: the primary organizational structure is numbered, with bullets serving as elaboration under the final numbered point.

## Meta-commentary assessment

193 responses (7.7%) contain meta-commentary about formatting instructions. The verifier is naturally robust against this because:

1. Format detection uses line-start regex (`^- \s` and `^\d+[.)]\s`), not keyword matching
2. Meta-commentary about "bulleted list" or "numbered list" appears in prose sentences, never at line starts in format-marker position
3. When meta-commentary lines DO start with `- ` (as in "- I must inform you that..."), this is semantically correct -- the model is using bullets for its entire response, including the meta-commentary

---

## Rubric justification

The rubric focuses on "primary organizational structure" to handle hybrid responses. Key design decisions:

1. **Numbered headings with bullet sub-items:** Classified by top-level structure. This matches the verifier's `_all_bullets_are_sub_items` logic and is semantically sound -- the primary structure is what the model chose as its organizing principle.

2. **Meta-commentary:** Judged by format used, not format discussed. A response that says "I cannot use numbered lists" but uses bullets is followed_a, regardless of the meta-commentary mentioning numbers.

3. **followed_neither:** Restricted to plain prose (no format markers) or equal dual-format. The rubric avoids making this a catch-all for ambiguous cases.

4. **No followed_both:** Exclusivity maintained. The constraints are genuinely mutually exclusive -- a response's primary structure is either bullets or numbers.
