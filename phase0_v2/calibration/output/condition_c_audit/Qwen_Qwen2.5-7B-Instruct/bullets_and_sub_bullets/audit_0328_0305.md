## Key Finding: Inline-Bullet Hybrid Responses

The most notable behavioral pattern in this audit is a Qwen-specific generation artifact: 198 responses (15.8% of b_to_a) embed `*` and `-` bullet markers within single-line paragraph text, producing a hybrid that is neither standard bullets nor clean paragraph form.

### Example (task=indoor_plants, score=0.000, label=followed_system)

> To care for common indoor plants effectively, start by understanding their specific needs, which can vary widely depending on the species. * Begin with light requirements; most indoor plants thrive in bright, indirect sunlight but some, like snake plants, can tolerate low light conditions. - For those needing more light, place them near windows that receive ample natural light throughout the day. * Watering is crucial; generally, allow the top inch of soil to dry out before watering again, ensuring the water drains properly to avoid root rot. - Overwatering is a common mistake; ensure pots have drainage holes...

This response has zero newline characters. It contains 7 star markers and 6 dash markers. When newlines are inserted before each `*` and `-`, it scores 1.000 as a proper bullet list.

### Ruling

These are **correctly classified as followed_system** (paragraph). The verifier's definition of "bullet points" requires line-separated structure -- markers at the START of lines, not embedded inline within continuous text. When rendered, these responses display as a single wall of text, not a visual bullet list. The model attempted a compromise by including marker characters without the line-break structure that makes them function as bullets.

This is a **measurement validity judgment**, not an error. The open question (below) captures the alternative interpretation.

## Near-Threshold Case

One response (task=printing_press, score=0.375) uses `--` (double dash) for sub-sub-bullets instead of `- ` (single dash with space). The scorer only recognizes lines starting with `- ` (single dash), so 10 of 16 lines go uncounted (1 star + 5 dash = 6/16 = 0.375). A human would classify this as bullet format (followed_user), but the score falls below T=0.433.

This is a minor measurement limitation affecting 1 response (0.04%). It is not a systematic issue since `--` sub-bullets are rare.

## Rubric Justification

The rubric defines bullet format as **line-separated structure** with `*` and `-` markers, matching the verifier's operational definition. This choice:

1. **Handles the inline-bullet hybrid** by classifying it as paragraph form (followed_b), consistent with how the text renders visually.
2. **Handles meta-commentary** by directing classification based on actual content formatting, not stated intent.
3. **Handles bare refusals** as followed_neither (no substantive content), though none were observed.
4. **Exclusivity is true** because the inverted-pair architecture makes followed_both and followed_neither mathematically impossible at any valid threshold.

### Open Question

Whether inline bullet markers (within single-line text) should count as "bullet format" is a judgment call. The current rubric says no -- visual line separation is required. An alternative interpretation would count any response using `*` and `-` as organizational markers as following the bullet instruction, regardless of line breaks. This alternative would reclassify 198 responses from followed_system to followed_user, changing the b_to_a system-follow rate from 17.0% to 1.2%.
