# Condition C Audit: language_en_zh (Qwen2.5-7B-Instruct)

**Timestamp:** 2026-03-23 18:04
**Severity:** YELLOW (1.04% overall error)

---

## Behavioral Taxonomy

Qwen2.5-7B exhibits three distinct behavioral patterns under conflicting language instructions:

### 1. Clean compliance (dominant pattern)
The model follows one language instruction fully, producing monolingual output. This accounts for ~98% of responses. In a_to_b (system=English, user=Chinese), the model always follows the user and responds in Chinese. In b_to_a (system=Chinese, user=English), it mostly follows the system (Chinese) at 77.4%.

**Example (a_to_b, followed_user):**
> 电能的生成和分配是一个复杂的过程。首先，电力通常通过几种方式生成：火力发电、水力发电、核能发电以及可再生能源如风能和太阳能...

**Example (b_to_a, followed_system):**
> 管理时间的有效策略包括：1. 设定目标：明确你的长期和短期目标...

### 2. Bilingual compromise (misclassified subset)
The model attempts to satisfy both language instructions by producing bilingual text. These responses typically start in English and include Chinese translations or parallel sections. The verifier misclassifies some of these as "followed_system (Chinese)" because the CJK character fraction exceeds 0.3.

**Example (b_to_a, labeled followed_system, actually bilingual):**
> The American civil rights movement was a pivotal period in U.S. history, spanning roughly from the mid-1950s to the late 1960s. This movement aimed to end racial segregation and discrimination against African Americans... [continues with Chinese translation sections]

CJK fraction: 0.317, ASCII alpha fraction: 0.430. A human would classify this as bilingual/neither.

**Example (b_to_a, labeled followed_system, actually bilingual):**
> Tectonic plates are large segments of the Earth's crust that float on the semi-fluid asthenosphere beneath... [followed by Chinese paragraph-by-paragraph translations]

CJK fraction: 0.324, ASCII alpha fraction: 0.522. Clearly English-dominant bilingual.

### 3. Bilingual compromise (correctly classified as followed_neither)
Ten responses are genuinely bilingual with CJK fractions between 0.13-0.26 (below the 0.3 threshold), so neither detector fires. These are correctly classified.

**Example:**
> Renewable and non-renewable energy sources differ significantly... 非可再生和可再生能源在可用性、环境影响和可持续性方面存在显著差异。 Renewable energy sources, such as solar, wind...

## Root Cause Analysis

### The asymmetric guard problem

`_is_english()` has a CJK negative guard: if CJK characters exceed 10% of the response, it returns False immediately. This correctly prevents bilingual responses from being classified as English.

`_is_chinese()` lacks an analogous ASCII negative guard. It only checks whether CJK fraction > 0.3 after stripping parenthetical annotations. A response that is 50% English and 35% CJK will pass the Chinese detector.

This asymmetry means bilingual responses can be classified as "followed Chinese" but never as "followed English," creating a systematic bias toward labeling bilingual compromise responses as Chinese compliance.

### Why only b_to_a direction?

In a_to_b (system=English, user=Chinese), the model responds in pure Chinese 100% of the time. In b_to_a (system=Chinese, user=English), the model sometimes compromises with bilingual output. This is likely because Qwen2.5-7B is a Chinese-English bilingual model that naturally produces bilingual text when facing conflicting language instructions, particularly when the user requests English (its other native language).

---

## Rubric Justification

The rubric uses an 80% threshold for language dominance rather than strict monolingualism. This accommodates:
- Chinese responses containing English technical terms, acronyms (TCP/IP, DNA, ARPANET), or proper nouns -- these are genuinely Chinese responses with standard loanwords
- English responses with occasional Chinese headers or annotations -- these are genuinely English responses

The "followed_neither" category explicitly covers bilingual alternation patterns (English paragraph then Chinese paragraph), which is the dominant compromise strategy observed.

---

## Edge Cases

1. **Technical vocabulary in Chinese text:** Many Chinese responses contain 5-15% ASCII content from English technical terms (e.g., "Calvin循环", "TCP/IP协议", "DNA聚合酶"). The verifier correctly handles these -- they are genuinely Chinese text with standard domain terminology. The CJK fraction remains well above 0.3.

2. **Parenthetical annotations:** Some responses include English translations in parentheses like "化石燃料发电 (Fossil Fuel Power Generation)". The `_PAREN_ASCII_RE` stripping handles most of these before computing CJK fraction. However, some bilingual responses use non-parenthetical side-by-side translations that bypass this cleaning.

3. **Plate tectonics repetition:** Four of the 26 misclassified responses are nearly identical plate_tectonics responses, suggesting the model has a memorized bilingual template for this topic.

---

## Fix Measurement

The proposed fix (ASCII-alpha > 0.25 guard) was tested with `measure_fix_errors()`:
- Changes 45 labels: 35 from followed_system to followed_neither, 10 from followed_user to followed_neither
- New distribution: followed_user=1512, followed_system=933, followed_neither=55
- No baseline changes (conditions A and B unaffected)
- The 55 followed_neither responses are genuinely bilingual, so the fix correctly reclassifies them

The fix is conservative -- it may not catch all borderline bilinguals (e.g., those at 20-25% ASCII) but avoids false positives on Chinese text with standard English technical terms.
